SurveillanceHound
NVR / IP-camera network monitor
RUNNING
  • ▸ Settings
  • ▸ Live dashboard
  • ▸ Help
What runs here. The daemon watches the selected interface for activity the surveillance threat model cares about: bulk transfers toward a camera, long-lived camera↔public sessions on non-routine ports, off-allowlist telemetry, behavioral anomalies vs each camera's learned baseline, new devices, new peers, and silent cameras. Saving regenerates /usr/local/etc/hound.toml and restarts the service. Headers only — no payload inspection, no DNS, no video.
